Introduction to Arrays

⏱️ 5 min read 📈 Beginner

An Array is one of the simplest and most widely used data structures in computer science. Think of it as a row of lockers in a hallway. Each locker has a specific number (an index), and you can store exactly one item in it.

How they work in memory

Arrays are stored in contiguous memory. This means all the elements of an array are stored right next to each other in the computer's RAM. Because of this, if you know where the first element is, and you know the size of each element, the computer can instantly calculate the exact location of any other element.

This is why accessing an element by its index is incredibly fast (an O(1) time complexity operation).

Key Characteristics

  • 0-Indexed: In most programming languages (like Python, Java, and C++), the first element is at index 0, not 1.
  • Fixed Size (usually): Traditionally, arrays are created with a fixed size. However, modern languages provide "dynamic arrays" (like Python's Lists) that resize themselves automatically.

Code Example

Here is how you initialize, access, and modify an array (list) in Python:

main.py Python
# Initialize an array of strings fruits = ["Apple", "Banana", "Cherry", "Date"] # Accessing elements (0-indexed) print(fruits[0]) # Output: Apple print(fruits[2]) # Output: Cherry # Modifying an element fruits[1] = "Blueberry" print(fruits) # Output: ['Apple', 'Blueberry', 'Cherry', 'Date']
